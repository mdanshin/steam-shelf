ПОДКЛЮЧЕНИЕ STEAM

Данные на этом устройстве

SteamID64 определяет профиль. API key передаётся gateway только для запроса библиотеки Steam и не сохраняется сервером.

  • Хранятся локально в IndexedDB
  • Не записываются на сервер, в Firebase или GitHub
  • Можно удалить одним действием
Где взять данные
  1. SteamID64: откройте Account Details и скопируйте Steam ID.
  2. API key: создайте ключ на официальной странице Steam.
API key является секретом: используйте его только на своём устройстве.
