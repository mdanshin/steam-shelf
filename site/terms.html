Steam Shelf

Приложение предоставляет личный интерфейс к данным, которые Steam разрешает читать с помощью предоставленного вами SteamID64 и Steam Web API key.

Ваши обязанности

  • Используйте только собственный API key и данные, к которым у вас есть право доступа.
  • Не передавайте ключ другим людям и удаляйте локальные данные на общих устройствах.
  • Не используйте приложение для автоматизированной нагрузки или обхода ограничений Steam Shelf, Steam и Firebase Authentication.

Доступность данных

Steam, Firebase Authentication и gateway являются отдельными компонентами. Синхронизация может временно не работать из-за ограничений, приватности профиля, квот, обслуживания или технических сбоев. Последний успешный локальный snapshot при ошибке сохраняется.
