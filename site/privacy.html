Ваши данные остаются под вашим контролем

Steam Shelf использует Firebase Authentication для входа через Google. Firebase получает данные, необходимые для аутентификации, включая идентификатор аккаунта, имя, email и аватар.

Что хранится на устройстве

SteamID64, Steam Web API key, библиотека и wishlist сохраняются в IndexedDB текущего браузера отдельно для каждого Firebase user ID. Они не синхронизируются между устройствами.

Что передаётся при синхронизации

При ручном обновлении SteamID64 и, только для библиотеки, API key передаются по HTTPS ограниченному gateway на api.danshin.ms. Gateway проверяет Firebase ID token, обращается только к фиксированным Steam API endpoints и возвращает нормализованный результат. SteamID64, API key, библиотека и wishlist на сервере не сохраняются.

Операционные данные

Gateway хранит краткосрочные ограничения частоты в памяти процесса. Дневные счётчики сохраняются после перезапуска в SQLite только под SHA-256-хешем Firebase user ID; записи старше предыдущего календарного дня удаляются при запуске сервиса и периодически во время работы. В технический журнал попадают идентификатор запроса, маршрут, HTTP-статус и длительность; тело запроса, Firebase token, Firebase user ID, SteamID64 и Steam API key не журналируются.

Удаление

Кнопка «Удалить локальные данные» удаляет SteamID64, API key и персональные snapshots из этого браузера. Выход из Google очищает данные из памяти, но оставляет локальный кэш для следующего входа того же пользователя.

IndexedDB не защищает от вредоносных расширений, XSS или человека с доступом к профилю браузера. API key также неизбежно присутствует в памяти браузера во время ручной синхронизации. Не сохраняйте ключ на чужом устройстве.
