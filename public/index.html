ПОДКЛЮЧЕНИЕ STEAM

Ваши данные доступа

SteamID64 определяет профиль. API key нужен только серверу для чтения списка принадлежащих вам игр.

  • Ключ хранится в AES-256-GCM шифровании
  • Не попадает в URL, логи или LocalStorage
  • Можно заменить или удалить в любой момент
Где взять данные
  1. SteamID64: откройте Account Details. Steam ID указан сразу под именем аккаунта — скопируйте все 17 цифр.
  2. API key: создайте персональный ключ на steamcommunity.com/dev/apikey.
SteamID64 не является секретом. API key никому не отправляйте.
