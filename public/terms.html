Условия использования

Steam Shelf — независимый инструмент для просмотра данных аккаунта Steam. Он не связан с Valve Corporation или Google.

Пользователь предоставляет только собственные SteamID64 и Steam Web API key и отвечает за соблюдение условий Steam. Доступность и полнота данных зависят от внешних API и настроек приватности профиля.

Сервис предоставляется без гарантии непрерывной доступности. Steam API key можно удалить в настройках приложения и отозвать на официальной странице Steam.

Редакция: 21 августа 2026 года.
