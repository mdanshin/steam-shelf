Политика конфиденциальности

Steam Shelf хранит Google subject, email, имя и аватар для идентификации аккаунта; SteamID64, зашифрованный Steam Web API key и персональные snapshots библиотеки и wishlist — для запрошенных пользователем функций.

Как защищены данные

Полный Steam API key не возвращается браузеру и хранится с authenticated encryption. Сессионные cookies имеют HttpOnly, а в базе хранится только хеш случайного session token.

Передача данных

Приложение обращается к Google только для входа, а к официальным Steam API — для синхронизации. Данные не продаются и не используются для рекламы.

Удаление

«Отключить Steam» удаляет ключ, SteamID и персональные snapshots. «Выйти» завершает только текущую сессию приложения. Для полного удаления Google-профиля из базы обратитесь к администратору deployment.
